# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.7.x | Yes |
| 0.3.x to 0.6.x | Security fixes until 2027-05-01 |
| 0.2.x | Security fixes until 2027-02-01 |
| 0.1.x (sdd-pilot) | No; please upgrade |

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's [Report a vulnerability](https://github.com/Dinusha-Ekanayake/specsteward/security/advisories/new) form (Security tab), not as a public issue. Include the version (`bash .sdd/bin/sdd --version`), what you did, and what you expected. You will get a reply within a week, and a fix or a plan within 30 days for confirmed issues.

See [docs/security.md](docs/security.md) for the threat model and what specsteward does and does not protect against.
